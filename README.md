# 100 Games Plus — v7

مشروع Android بلغة Kotlin. هذه النسخة تضيف 10 ألعاب حركة جديدة إلى الألعاب السابقة:

1. سباق السيارات — تبديل المسارات باللمس وتفادي السيارات.
2. متاهة آكل النقاط — أسلوب متاهة مستوحى من ألعاب جمع النقاط وتفادي الأشباح.
3. مطاردة الأشباح — متاهة وجمع نجوم وتجنب الأشباح.
4. مدافع الفضاء — تحريك السفينة باللمس وإطلاق آلي.
5. سباق الدراجات — تبديل المسارات وتفادي العوائق.
6. مغامرة النهر — توجيه القارب بين العوائق.
7. متاهة الكرة — تحريك كرة داخل المتاهة.
8. عدّاء الغابة — القفز باللمس فوق العوائق.
9. جامع الفقاعات — تحريك السلة لالتقاط الفقاعات.
10. الهروب من المتاهة — جمع النقاط والمفاتيح والابتعاد عن الأشباح.

## الرفع إلى GitHub Actions
ارفع هذا الملف ZIP إلى جذر المستودع ليقوم `unpack-build.yml` بفك المشروع وبنائه. يجب أن يكون `settings.gradle` في جذر الأرشيف. لا يحتوي هذا الأرشيف على مجلد `.github` كي يحتفظ المستودع بسير العمل الحالي.

تم إعداد الأكواد وملفات التسجيل والـ Manifest؛ لم يُنفّذ بناء Gradle فعلي في بيئة الإعداد هذه، لذا يجب مراجعة نتيجة GitHub Actions.
