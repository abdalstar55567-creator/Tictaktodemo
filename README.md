# 100 Games Plus — ألعاب متنوعة بلغة Kotlin

مشروع تطبيق Android يضم ألعاباً قصيرة ومتنوعة، ويستخدم واجهة عربية وأساساً مشتركاً لشاشات اللعب.

## الألعاب الجديدة في هذه النسخة

أُضيفت ثماني ألعاب بأفكار مختلفة عن ألعاب السرعة والذاكرة والأسئلة وسباقات الحركة الموجودة مسبقاً:

1. **دافع الصناديق (Sokoban):** ادفع الصندوق إلى الهدف، مع التخطيط لتجنب حشره في الجدران.
2. **أبراج هانوي:** انقل الأقراص بين ثلاثة أعمدة مع الالتزام بعدم وضع قرص كبير فوق قرص أصغر.
3. **فك الشفرة (Mastermind):** استنتج ترتيب أربعة ألوان من تلميحات الأماكن الصحيحة والخاطئة.
4. **تحدي الأعواد (Nim):** لعبة استراتيجية ضد الحاسوب؛ خذ من 1 إلى 3 أعواد مع تجنب أخذ العود الأخير.
5. **قفز القطع (Peg Solitaire):** اقفز بقطعة فوق قطعة أخرى لإزالتها، وحاول إنهاء اللوحة بقطعة واحدة.
6. **عبور النهر:** انقل المزارع والذئب والماعز والملفوف مع مراعاة قواعد السلامة.
7. **لغز الصورة المخفية (Nonogram):** استعمل أدلة الصفوف والأعمدة لملء شبكة تكشف صورة.
8. **وصل الأنابيب:** أدر قطع الأنابيب لبناء مسار للماء.

## الملفات التي عُدّلت

- `app/src/main/java/com/example/tictactoe/SokobanActivity.kt` — جديد.
- `HanoiActivity.kt`, `MastermindActivity.kt`, `NimStrategyActivity.kt`, `PegSolitaireActivity.kt`, `RiverCrossingActivity.kt`, `NonogramActivity.kt`, `PipeConnectActivity.kt` — ألعاب جديدة.
- `Games.kt` — تسجيل الألعاب في قائمة التطبيق.
- `app/src/main/AndroidManifest.xml` — تسجيل شاشات الألعاب الجديدة.

## طريقة إضافة لعبة جديدة

1. أنشئ ملف Kotlin داخل `app/src/main/java/com/example/tictactoe/`.
2. اجعل شاشة اللعبة ترث `BaseGameActivity`، وحدد `gameTitle`، ثم أنشئ الواجهة في `onCreate` باستخدام `initScreen(...)` وأدوات `Ui` أو الدوال المساعدة.
3. سجّل النشاط داخل `app/src/main/AndroidManifest.xml`.
4. أضف `GameInfo(...)` إلى `Games.all` في `Games.kt`.
5. ابنِ المشروع عبر Android Studio أو GitHub Actions وتحقق من سجل البناء.

## البناء والتحقق

لم تتوفر في بيئة التعديل خدمة تنزيل اعتمادات Gradle، لذلك يجب تشغيل بناء `assembleDebug` في بيئة Android/Gradle متصلة بالإنترنت للتأكد النهائي.
