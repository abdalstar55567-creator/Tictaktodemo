١٠٠ لعبة وأكثر — دليل المشروع (للمطوّر ولأي ذكاء اصطناعي توليدي)
تطبيق أندرويد (Kotlin) يجمع ألعاباً بسيطة تحت قائمة رئيسية. الواجهات كلها تُبنى بالكود (Views) بدون Material وبدون ملفات تصميم للألعاب، والنصوص عربية (RTL).
١) كيف تحصل على ملف APK (بدون حاسوب)
ارفع ملف ZIP للمشروع إلى جذر المستودع على GitHub (Add file ← Upload files ← Commit).
يعمل تلقائياً workflow اسمه Unpack ZIP and build APK: يفك الضغط، يبني، ويحفظ النتيجة.
تأكد في سجل خطوة Unpack من السطر Games registered: N (N = عدد الألعاب).
من صفحة التشغيل ← Artifacts نزّل apk-100-games وفك ضغطه لتجد app-debug.apk.
أزل التطبيق القديم من الهاتف قبل تثبيت الجديد (كل بناء يُوقَّع بمفتاح debug مختلف، فالتحديث فوق القديم يفشل). هذا يمسح الدرجات المحفوظة.
احذف أي ZIP قديم من الجذر قبل رفع الجديد (الـ workflow يستخدم أحدث ملف ZIP ويحذف الباقي).
