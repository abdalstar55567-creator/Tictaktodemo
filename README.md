# 100 Games Plus — نسخة إصلاح ألعاب الحركة

مشروع Android بلغة Kotlin. جرى تقليص الإضافات من عشر ألعاب متشابهة إلى خمس ألعاب حركة فقط، مع إزالة النسخ المكررة من قائمة اللعب.

## ألعاب الحركة الخمس
1. **سباق السيارات:** تبديل المسارات وتجنب السيارات القادمة؛ الاصطدام ينهي الجولة وتزداد السرعة مع النقاط.
2. **متاهة آكل النقاط:** تحرك بالسحب بين الممرات، واجمع النقاط وتجنب الأشباح؛ جمع النقاط ينهي الجولة مع مكافأة.
3. **مدافع الفضاء:** تحريك السفينة باللمس، إطلاق تلقائي، وتجنب الأعداء.
4. **عدّاء الغابة:** اقفز باللمس فوق العوائق؛ الاصطدام ينهي الجولة.
5. **تحدي الفقاعات السامة:** التقط الفقاعات الزرقاء، وتجنب الحمراء؛ التقاط الحمراء أو تفويت ثلاث زرقاء ينهي الجولة، والوصول إلى 15 نقطة يكمل التحدي.

## الرفع إلى GitHub Actions
ارفع ملف ZIP إلى جذر المستودع ليقوم سير العمل الحالي بفك المشروع وبنائه. يجب أن يكون `settings.gradle` في جذر الأرشيف. الأرشيف لا يحتوي على مجلد `.github` حتى يحتفظ المستودع بسير العمل الموجود.

**تنبيه:** أُجريت مراجعة ثابتة للتعديلات، لكن لم يُنفذ بناء Gradle كامل في هذه البيئة. تحقق من نتيجة GitHub Actions قبل اعتبار النسخة ناجحة.
